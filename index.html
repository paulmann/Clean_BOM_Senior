Clean_BOM_Senior

Strip the invisible bytes, keep the ones that matter

Removes UTF-8 BOM and CRLF from source files, and knows when a BOM is load-bearing: byte-exact detection, atomic writes, Smart BOM Policy, CI gate, npm package and PowerShell port.

What it does

  • Byte-exact detection: clean files are never rewritten
  • Refuses UTF-16/32 and binary files outright
  • Exit code 10 as a CI gate for dirty trees

Built with

Batchfile, JavaScript, PowerShell, Python, Shell
